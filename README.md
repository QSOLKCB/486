# 486

A browser-based retro PC lab: a modular, CPU-first path toward a 486-class PC,
using plain HTML, CSS, and JavaScript. Persistent virtual disks and retro audio
are goals, not implemented features.

**Status: foundation only.** This repository currently contains design contracts,
original diagnostic bytes, and executable reference checks—not an emulator.
Passing these checks is neither ISA conformance nor a formal proof.
